# MCT Immersive Technology
Energy Technology addon for Immersive Engineering, forked from Immersive Tech.<br/>

# Overriding machines
Every machine here can be reskinned, retuned and rewired with an ordinary
resource pack and data pack, the same way as any mod built on Immersive
Convergence. See its README's
[Overriding content](https://github.com/tgstyle/Immersive-Convergence/blob/1.20.1-1.0-Release/README.md#overriding-content)
section for the file paths, the multiblock JSON format, and what a `/reload`
does and does not pick up live.

Immersive Technology's own machine ids, used under `data/immersivetechnology/`
and `assets/immersivetechnology/`, are `advanced_coke_oven`, `alternator`,
`boiler_liquid`, `boiler_solid`, `boiler_tank`, `cooling_tower`, `distiller`,
`electrolytic_crucible_battery`, `gas_turbine`, `heat_exchanger`,
`melting_crucible`, `radiator`, `radiator_horizontal`, `solar_melter`,
`solar_reflector`, `solar_tower`, `steam_turbine` and `steel_sheetmetal_tank`.
